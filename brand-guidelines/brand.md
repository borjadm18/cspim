# Content Store — Brand Guidelines

## Overview

Content Store is a modern enterprise SaaS platform connected to PIM ecosystems.
The brand should feel clean, intelligent, scalable and approachable.

The visual identity combines:

* enterprise reliability
* modern product design
* friendly interactions
* technical precision

The product sits between:

* PIM
* DAM
* Content Operations
* Integrations
* Data Governance
* Automation

The brand must avoid looking:

* old enterprise
* corporate stock style
* over-designed
* overly futuristic

The goal is:
simple, premium, modern and scalable.

# Logo

## Concept

The logo represents:

* connected content
* modular information
* structured data
* approachable technology

The floating blocks symbolize:

* assets
* metadata
* structured content
* distributed systems

The smile shape adds:

* friendliness
* simplicity
* accessibility

## Logo Usage

* Prefer monochrome logo on dark surfaces
* Use full-color logo for marketing pages
* Keep generous whitespace around logo
* Never stretch or distort the symbol

# UI Guidelines

## Components

Use:

* soft shadows
* rounded corners
* subtle borders
* layered surfaces

Avoid:

* heavy skeuomorphism
* glossy effects
* oversized gradients
* sharp enterprise tables

## Dashboard Style

* modular cards
* data-first layouts
* strong hierarchy
* comfortable spacing
* readable tables
* modern filters/search

---

# Iconography

Icons should:

* be simple
* outline-based
* rounded
* consistent stroke width

Avoid:

* complex illustrations
* cartoon icons
* 3D icons

---

# Motion

Animations should feel:

* subtle
* smooth
* premium

Use:

* soft fades
* slight movement
* elegant hover states

Avoid:

* exaggerated transitions
* flashy animations

# Brand Values

## Structured

## Scalable

## Human

# AI / Code Generation Instructions

When generating UI:

* prioritize clarity over decoration
* maintain strong spacing
* use minimal but elegant gradients
* keep interfaces clean and modular
* prefer dark mode aesthetics
* avoid visual clutter

The platform should feel:
“enterprise-grade, but modern and enjoyable to use.”
